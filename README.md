## mini-logger
高性能异步日志库｜C 底层数据结构 + C++17 RAII 封装｜Linux 专属
一个轻量、高并发、低延迟的异步日志组件，主打 多生产者单消费者(MPSC)无锁队列 + 固定块内存池，规避频繁 malloc/free 与磁盘IO阻塞，适合底层服务、后端、基础设施项目练手与复用。

---
### ✨ 项目亮点
- 分层架构：纯 C 实现底层数据结构，C++ 仅做上层 RAII 封装，解耦清晰，可单独对底层 C 模块单元测试
- 内存池优化：预分配固定块内存池，复用内存块，减少系统调用与内存碎片，模仿 Linux slab 分配思想
- 无锁环形队列：基于 C11 stdatomic.h 实现 MPSC 无锁队列，多线程写日志无锁竞争，性能更高
- 真正异步落盘：业务线程只写内存队列，后台线程统一刷盘，完全解耦业务与磁盘IO阻塞
- 安全 RAII 生命周期：C++ 类托管线程、内存池、文件资源，析构自动优雅退出、刷完剩余日志、释放资源
- 工程规范：CMake 构建、ASAN 内存检测、结构化代码、Doxygen 注释、无内存泄漏

### 📐 整体架构
分层结构：底层C基础设施层 → 上层C++封装层 → 业务测试入口
```
mini-logger
├── src/c_core        # 纯C底层核心（无C++依赖）
│   ├── mempool       # 固定块内存池，复用日志内存
│   └── ringbuffer    # MPSC 无锁环形队列
├── src/cpp_wrapper   # C++17 上层封装
│   └── logger        # RAII 日志管理、后台消费线程、对外日志接口
└── example           # 多线程压测 demo
└── Demo(learn)       # 学习使用的 demo
```

### 数据流
业务多线程写入日志 → 内存池取块 → 推入无锁环形队列 → 后台线程异步刷盘 → 内存块归还复用

### 📦 模块详细说明
#### 1. 内存池 mempool
   一次性预分配连续内存，切割为固定大小日志块，全程避免频繁 malloc/free。
- 对外接口：创建/销毁内存池、块分配、块归还
- 空闲块链表管理，复用效率高
- 规避内存碎片、减少系统调用开销
#### 2. 无锁环形队列 ringbuffer
   基于 C11 原子变量实现 多生产者、单消费者 模型。
- 多业务线程无锁入队，无 mutex 竞争
- 后台单线程专属出队，模型简单稳定
- 队列满直接丢弃日志，避免阻塞业务线程（可扩展阻塞策略）
#### 3. 上层 Logger 封装
   统一管理所有资源与线程生命周期，对外提供简洁日志接口。
- 可变参数格式化日志，支持多日志级别
- 后台线程循环消费、异步写文件
- 析构函数保证：收尾日志刷盘、线程优雅退出、资源全部释放
- 禁止拷贝，保证全局唯一日志实例资源安全

### 💡 工程设计取舍
1. 固定块内存池：牺牲灵活性，换取极低的分配开销与无碎片内存管理
2. MPSC 无锁队列：适配日志典型场景（多写单读），最大化业务写入吞吐
3. 异步刷盘：业务线程不阻塞IO，极致降低业务延迟；代价是崩溃时少量队列日志可能丢失
4. 队列满丢日志：优先保证业务不卡顿，适合高吞吐日志场景，可后续扩展阻塞/告警策略
